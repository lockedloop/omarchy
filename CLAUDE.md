# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Omarchy is a Linux distribution built on Arch Linux with Hyprland (Wayland compositor). The codebase consists of ~170 Bash shell scripts that manage installation, configuration, theming, and system updates.

## Repository Structure

<!-- markdownlint-disable MD013 -->
- `bin/` - All executable commands (`omarchy-*` pattern, symlinked to PATH)
- `config/` - Default configuration templates for 30+ applications
- `default/` - System defaults sourced by user configs (hypr bindings, bash, themed templates)
- `themes/` - 15 stock color themes (catppuccin, rose-pine, tokyo-night, etc.)
- `install/` - Modular installation system (helpers, preflight, packaging, config, login, post-install)
- `migrations/` - 230+ timestamped shell scripts that run once per system on update
- `applications/` - Desktop application definitions
<!-- markdownlint-enable MD013 -->

## Development Commands

```bash
# List all omarchy commands
compgen -c | grep -E '^omarchy-' | sort -u

# Read a command's source to understand it
cat $(which omarchy-theme-set)

# Create a new migration (ALWAYS use --no-edit to avoid interactive editor)
omarchy-dev-add-migration --no-edit

# Full system update (runs migrations)
omarchy-update
```

## Architecture

**Configuration Hierarchy:**
1. Defaults from `~/.local/share/omarchy/default/` (read-only, sourced)
2. Current theme from `~/.config/omarchy/current/theme/` (generated by theme-set)
3. User overrides in `~/.config/hypr/`, `~/.config/waybar/`, etc.

**Command Naming Pattern:** `omarchy-<category>-<action>`
<!-- markdownlint-disable MD013 -->
- `omarchy-refresh-*` - Reset config to defaults (creates backups)
- `omarchy-restart-*` - Restart services/applications
- `omarchy-toggle-*` - Toggle features on/off
- `omarchy-theme-*` - Theme management
- `omarchy-pkg-*` - Package management
- `omarchy-update-*` - System updates
- `omarchy-cmd-*` - System commands
- `omarchy-setup-*` - Initial setup tasks
<!-- markdownlint-enable MD013 -->

**Update System:** Migrations are timestamped shell scripts in `migrations/` that run once per system. They handle config updates, new dependencies, and one-time setup tasks.

**Theme System:** `omarchy-theme-set` copies theme files, generates dynamic configs from `.tpl` templates, restarts components, and calls hooks.

## Critical Rules

**NEVER modify `~/.local/share/omarchy/`** - This directory is git-managed. Changes will be lost on update and cause conflicts.

**ALWAYS read from `~/.local/share/omarchy/`** - Safe and useful for understanding commands and defaults.

**Safe edit locations:**
<!-- markdownlint-disable MD013 -->
- `~/.config/` - User configuration
- `~/.config/omarchy/themes/<name>/` - Custom themes
- `~/.config/omarchy/hooks/` - Automation hooks (theme-set, font-set, post-update)
<!-- markdownlint-enable MD013 -->

**Component reload behavior:**
<!-- markdownlint-disable MD013 -->
- Hyprland: Auto-reloads on config save
- Waybar: MUST run `omarchy-restart-waybar`
- Walker: MUST run `omarchy-restart-walker`
- Terminals: MUST run `omarchy-restart-terminal`
<!-- markdownlint-enable MD013 -->

**Hyprland window rules:** Syntax changes frequently. Always fetch current docs from https://github.com/hyprwm/hyprland-wiki/blob/main/content/Configuring/Window-Rules.md before writing rules.
